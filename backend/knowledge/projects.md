# Akash's projects at a glance

## Projects overview
Projects Akash has built, in the order to present them. The first three are live and public, so lead with them and give their links; his work projects at UBS come after, and have no public link.

Live projects:
- Chikki (https://akashbhalshankar.com): a voice-first AI career assistant and interactive portfolio (React, FastAPI, WebSockets, Edge-TTS, multi-provider LLM routing).
- ShareInSync (https://shareinsync.akashbhalshankar.com): a peer-to-peer file sharing progressive web app (React, WebRTC, Cloudflare Workers) with no server storage.
- NaChitram (https://chromewebstore.google.com/detail/scioflow-screen-webcam-wh/nklfcnddfghefifdpgmlkccbanmmoido): a free Chrome extension that records screen and webcam with a live whiteboard and a private teleprompter, with everything processed locally in the browser. It is available in the Chrome Web Store.

Work projects at UBS (no public link):
- Request Management Service: a LangGraph-based multi-agent platform with self-validating reflection agents.
- NavLearn (Vibe Testing): AI-assisted conversion of BDD specifications into runnable test scripts.
- AgriMentor: an agricultural AI assistant that reads soil-test inputs (PDF, image, text) through FastAPI backends.
