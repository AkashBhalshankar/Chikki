# Akash's projects at a glance

## Projects overview
Projects Akash has built, each in one line (details are in the resume and the project notes):
- Chikki: a voice-first AI career assistant and interactive portfolio (React, FastAPI, WebSockets, Edge-TTS, multi-provider LLM routing).
- NaChitram: a free Chrome extension that records screen and webcam with a live whiteboard and a private teleprompter, with everything processed locally in the browser.
- ShareInSync: a peer-to-peer file sharing progressive web app (React, WebRTC, Cloudflare Workers) with no server storage.
- AgriMentor: an agricultural AI assistant that reads soil-test inputs (PDF, image, text) through FastAPI backends.
- Request Management Service at UBS: a LangGraph-based multi-agent platform with self-validating reflection agents.
- NavLearn (Vibe Testing) at UBS: AI-assisted conversion of BDD specifications into runnable test scripts.
